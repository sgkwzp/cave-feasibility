# 物体观测通道：补齐 EgoPER 五任务

2026-10-27。按用户要求补做 Coffee、Tea、Oatmeal；Quesadilla/Pinwheels 复用此前已核验结果。本轮新增训练次数为 0，沿用唯一种子 20261027 的观察器。

## 直接结论

主比较固定为 **AEM+时长+固定 ROI 对 AEM+时长**。新增三任务的步骤宏 AUROC 平均增量为 **+2.42 [+0.04, +4.75] 点**（录像聚类 95% CI），其中 3/3 个任务点估计为正。

五任务平均增量为 **+2.95 [+1.28, +4.63] 点**；旧两任务平均为 **+3.74 [+1.39, +6.17] 点**。判断泛化时以新增三任务为主，不用五任务平均掩盖退化。

本轮冻结的进一步扩展条件通过。可继续验证预测边界和实际结果证据依赖；当前仍只是冻结物体观测与简单融合，不能据此确证完整 CAVE 或“效果脑补”机制。

## 为什么先前只有两个任务

先前用已具备完整观测缓存的 Quesadilla/Pinwheels 完成最小可行性和匹配 ROI 对照，目的在于控制验证成本。该范围不能代表五任务。收到本次补齐要求后，固定方法、校准与比较规则，为其余三任务重新解码和提取观测特征。

三任务此前用于 AEM/时长以及其他方向的诊断，故称为“本轮固定方案的跨任务验证”，不称从未接触的独立数据集。旧门槛及失败记录原样保留，本次是用户授权的任务覆盖扩展。

## 核验与文件

旧两任务 AEM/Duration 校准分数重建误差 ≤8.88e-16；新任务官方 checkpoint 与原导出分数、训练/评测源码哈希匹配。原实验和前轮报告均未改写。

每条新增录像首段独立重建 ROI 池化向量，最大误差 1.27e-07。3030 段与冻结清单逐项一致，9090 个帧引用与指定时间/边界舍入规则完全对应。AUROC/AP 对 sklearn 重建最大误差 3.33e-16。主比较置信区间从保存的配对抽样数组重建通过。

初次启动因 Windows 路径分隔符导致服务器哈希核对找不到文件，在计算前退出；修复路径序列化后执行。没有修改数据、分数、超参数或纳入规则。

- 原两任务证据继续保存在 `../follow-up/`；大帧特征与检测缓存保留在服务器。
