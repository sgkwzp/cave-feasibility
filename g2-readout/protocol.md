# G2：冻结表示的实例状态／关系读出

日期：2026-10-27。依据上级 verification-plan.md 的 G2 执行；保留既往失败门槛。仅诊断，不启动新网络训练、CAVE、CEI 或 CC4D。

## 冻结对象

- 五任务全部纳入，种子 20261027。官方正常 train 用于拟合与五折录像分组选择岭参数；官方正常 val 作为最终读出留出集。测试错误段不进入本实验。公开 AEM 权重不变；train 的交叉拟合结果不是 AEM 权重未见数据，val 也不声称从未用于官方 checkpoint 选择。
- 只纳入既有观测 manifest 中、状态和关系句子均非空、与 GT 段时间一致的记录。多条老师记录按段合并，同一批段用于所有方法。每步至少五条拟合录像；缺失率和被排除步骤全部报告。GT 边界和步骤只作本次机制诊断。
- 同一目标：发布场景图的 attribute_sentence 与 relation_sentence，经冻结 EVA02 文本编码器分别编码，每句 L2 归一化后取均值，再分别归一化。保留两个目标并等权合并。它是发布状态／关系伪标签的固定语义读出目标，不冒充 AEM 内部学习过的 GNN／视觉联合投影。
- 目标类均值、输入类均值、尺度和正则选择只使用当折拟合集。目标先扣除拟合集的步骤类均值，类均值基线预测零。

## 四路和控制

1. 步骤类均值。
2. AEM state/relation token 拼接；附报投影前 CLS（若缓存没有则一次冻结前向导出）。
3. AEM 完整增强段表示，即官方检测器接收的段均值；另保留输入 FPN 段均值以定位信息变化。
4. 原段三张尾帧的固定 ROI 观测，复用既有编码、取帧与检测缓存；全局尾帧为对照。

背景控制：同帧两个 ROI 的并集外 patch 均值，剔除无剩余 patch 的帧并记录回退。视频身份代理：同录像其他步骤的全局特征均值（排除整个目标步骤），以及从文件名读取的参与者／场次 one-hot；绝不使用留出录像老师标签构造身份代理。未知类别编码为零。

各读出先将特征 L2 归一化，再按拟合集步骤均值中心化；统一以拟合集均方范数缩放。每任务、每目标用相同岭回归，目标损失为均方误差。alpha = [0.0001,0.001,0.01,0.1,1,10]，五折录像分组验证选择，平局取较强正则；没有错误标签选择。所有方案同样预算，不给某一路额外调参。

附报 nuisance 增量：以背景＋视频场景＋参与者／场次为控制，比较控制本身、控制＋token、控制＋完整表示、控制＋观测。每个特征块独立使用拟合统计尺度，拼接后等权，不使用留出目标做残差化。

## 指标与决定

- 每任务报告状态、关系的原始 MSE，除以类均值残差 MSE 的 NMSE，以及 R²=1−NMSE；主要汇总为目标等权、任务等权 R²。同步骤宏敏感性结果、每段预测和误差一起保存。
- 2000 次配对录像簇 bootstrap，任务内重采样，报告差值 95% 区间；等效判断使用预定 ±0.02 R² 的 90% 区间。只有差异区间跨零不算等效。
- 若 token 相对均值增益的 90% CI 全在 ±0.02，且观测相对 token 的 95% CI 下界 >0，可支持“该目标在该线性读出下 token 信息不足”。不能由一次线性探针证明没有任何实例信息或容量因果瓶颈。
- 若 token 对均值 R² 的 95% CI 下界 >0，并在身份／背景控制后仍有增量，删除“token 只是类均值”的主张。若只比类均值好而控制后无增量，说明可读出实例相关信息但效果语义来源未区分。
- 若 token、完整表示与观测差的 90% CI 均在 ±0.02，观测优势未建立。其它情况明确为不确定，不追加模型挽救。
- 教师噪声：检查是否有同一帧的独立重复伪标签；没有重复或独立真值时，四路均标记“真实噪声下限不可识别”。48.4% 逐帧全对率不是平方误差噪声下限；类内方差和同帧重复一致性也不冒充物理真值准确率。
